# Entra ID Identity 

A Microsoft Entra ID environment set up for a hospital, used to manage who gets access to what and how. Everything here is synthetic. No real users or organization.

## What this will cover
- Users and groups by department (nursing, lab, billing, IT)
- Onboarding, department transfers, and offboarding
- MFA and Conditional Access policies
- Privileged Identity Management (PIM) so admin roles are only active when needed
- Access reviews for managers to confirm who still needs access
- An app registration with single sign-on

## Why hospitals
Hospitals have a lot of staff moving between units, temp and travel workers, and systems holding patient data. Getting access right matters a lot there, and it gets messy fast.
